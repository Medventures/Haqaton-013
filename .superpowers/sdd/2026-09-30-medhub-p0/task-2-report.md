# Task 2 report: canonical masking and evidence boundary

## Changes

- Added `backend/app/grounding.py`: conservative per-segment normalization, whole-transcript PII detection, offset projection back to stable IDs/times, canonical-source assertion, populated-field path resolution, and server-owned evidence links. Cross-boundary matches place a placeholder in the first touched segment and remove covered characters from later segments. Canonical text is the newline join of final projected segments. Raw speaker metadata is removed from projected segments. Offset spans and original values are not stored in the canonical source.
- Refactored `backend/app/pii.py` to expose the detector spans to the projector and detect IIN digits split by newlines. The existing text masking method still uses the same detector.
- Updated the LLM provider contract in `backend/app/providers/base.py` and implementations in `llm.py` and `demo.py` to consume `CanonicalTranscript` and return `ExtractionResult`. OpenAI receives a frozen JSON snapshot of only revision and masked `{id,start,end,text}` segments, with `store=False` and `text_format=ExtractionResult`. It rejects a malformed or detectably unmasked source before transport. It validates the structured result, template keys, forbidden diagnosis code, and all evidence claims against that frozen snapshot; output validation gets two total attempts. Transport errors get one call. Callbacks report only stage key, status, and attempt.
- Demo extraction accepts only the existing one-segment synthetic fixture with its actual ID and 0–34 second interval. Its evidence uses literal quotes in that fixture and has no model-supplied timestamps.
- Added `backend/tests/test_grounding.py` and adapted `backend/tests/test_providers.py` for the canonical envelope, cross-segment masking, path/quote/ID validation, retry and transport behavior, fixture-only demo, and a source-mutation-during-await regression.

Official Structured Outputs guidance requires root objects and closed schemas; see https://developers.openai.com/api/docs/guides/structured-outputs#supported-schemas. The configured model and credentials were not changed; all external calls in tests used fake clients.

Quotes prove literal source location only, not clinical truth. The rule-based detector can miss identifiers outside its patterns, so it is not a guarantee of complete de-identification. No browser, main API, database, service, or deployment files were changed.
