# AI, privacy, and provider implementation

Implemented replaceable STT, LLM, MIS, and storage protocols and adapters under `backend/app/providers/`. The local Whisper adapter loads `small`/CPU/int8 lazily and transcribes only a supplied audio path in a worker thread. The separate demo endpoint uses a synthetic transcript; its extractor rejects all other text. The OpenAI adapter re-masks input at its own boundary, calls Responses structured parsing with `store=False` and SDK retries disabled, validates the strict shared schema, and permits one retry only for invalid output. Provider exceptions carry generic messages without clinical text or credentials. Mock MIS document IDs are deterministic for a consultation, and local storage rejects traversal and symlink keys.

`PIIMaskingService` masks Kazakhstan IINs, common phone formats, emails, contextual birth dates, labelled document numbers, street addresses, and common Cyrillic full-name forms. Its result contains only masked text and entity type/placeholders; no reverse mapping exists. Normalization changes whitespace only, leaving uncertain clinical terms and measurements unchanged.

Verification: `cd backend && ../.venv/bin/python -m pytest tests/test_pii.py tests/test_providers.py -q` — **14 passed**. Tests cover PII removal while retaining medicines/doses/vitals, ordinary clinical speech that should not be mistaken for a name, invalid structured output and bounded retry, outbound masked input, safe upstream errors, demo fixture restrictions, fake local STT mapping, storage traversal/symlink rejection, and mock MIS idempotence. No model download, real patient data, or external API call is used in tests. A full backend pytest command stalled on the first API `TestClient` test inside the sandbox; the root integration worker is running that suite with approved unrestricted execution.

Limitations: regex-only PII cannot reliably identify every free-form name, address, spoken-digit identifier, or ASR error. Local NER was deferred because no validated offline Kazakhstan model is included. Real audio quality and model download, live OpenAI responses, and a real UMC/MIS contract remain unverified; the MIS adapter is explicitly a mock. Clinical content from AI remains a draft for physician review.
